# Independent review round 1: remediation ledger

This is the implementer's record of how each finding of the first independent review was handled. It is NOT an independent receipt: independent reviewers re-review the final revision, and every "fixed" below is a claim for them to test.

- **Reviewed revision:** the round-1 reviewed revision (the tested revision behind it is the round-1 tested revision, the later commit is documents only).
- **Fixes:** made on top of the reviewed revision.


This record keeps test names, counts and dates, not revision identifiers: the release is built as one clean revision, so a history reference would not resolve.

## Method (the regression-proof rule)

1. Each regression test was written first. It was then run against a pristine tree of the reviewed revision: `git archive the round-1 reviewed revision... | tar -x` into a scratch directory, with only the new test files and helpers copied in, and `npx vitest run --root <scratch>`. Every P0 and P1 test is RED there and GREEN on the fix. The failing assertions are quoted below (they are the tool's own output, shortened).
2. Each fixed P0/P1 has a seeded mutation control in `scripts/mutation-controls.mjs` (id prefix `r1-`): the fix is removed from a disposable copy and the named tests must fail. All 20 are killed (result at the end).
3. Combination and metamorphic tests for the decision code are committed as tests (`tests/unit/review-round1-decision.test.ts`): each of 14 uncertainty sources alone and in all 91 pairs forces INCOMPLETE and keeps the known findings; adding PASSED evidence never changes an assessment (200 seeded random graphs); adding any non-PASSED evidence forces INCOMPLETE without changing findings; check result order never matters; several checks sharing one check id are never hidden by a passing one; degrading baseline evidence never lowers the verdict rank; NO_KNOWN_IMPACT never coexists with an unknown or a finding.
4. Unit level tests and single probes were run for each fix. The full gate (host gate, PostgreSQL 17, Node 22.12 floor, Compose) has NOT been run by the implementer at this revision; see "Not run".
