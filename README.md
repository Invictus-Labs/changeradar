# ChangeRadar

Self-hosted change-impact analysis: see which known consumers a proposed manifest change can break.

**Status: pre-MVP, under development.** Nothing in this repository is a release. The product contract is [docs/prd/changeradar.md](docs/prd/changeradar.md).

- License: MIT
- Runtime: Node.js 22+ TypeScript API and worker, PostgreSQL, React graph and report view
- Standalone: no account, license server, telemetry or paid provider is required.

This README is replaced with installation and operator documentation as the MVP lands.
